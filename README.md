# 🌑 Kinetic Noir - Free Elementor Landing Page

Kinetic Noir est un template Elementor de haute performance, conçu pour une esthétique sombre, brutale et cinétique. Ce dépôt fournit à la fois le **plugin compagnon** (pour les widgets personnalisés) et le **template JSON** à importer.

## ✨ Caractéristiques

- 🌑 **Design Dark Brutalist** : Une interface sombre avec des contrastes élevés et une typographie forte.
- 🚀 **Performance** : Utilise Tailwind CSS pour un rendu léger et précis.
- 🧩 **Widget sur Mesure** : Inclut un plugin WordPress qui ajoute un widget Elementor spécifique pour ce design.
- 📱 **Fully Responsive** : Adapté pour mobiles et tablettes.

## ⚙️ Installation Gratuite

Pour mettre en place cette landing page gratuitement, suivez ces étapes :

### 1. Installation du Plugin (Widgets)
1. Téléchargez ce dossier (ou clonez-le).
2. Compressez le contenu du dossier (ou le dossier lui-même) en `.zip`.
3. Dans WordPress, allez dans **Extensions > Ajouter** et téléversez le fichier `.zip`.
4. **Activez** l'extension "Kinetic Noir Elementor Template".

### 2. Importation du Template Elementor
1. Assurez-vous qu'**Elementor** est installé et activé.
2. Allez dans **Elementor > Modèles > Modèles enregistrés**.
3. Cliquez sur **Importer des modèles** et choisissez le fichier `kinetic-noir-template.json` présent dans ce dossier.
4. Une fois importé, créez une nouvelle page et insérez le modèle depuis votre bibliothèque.

### 3. Utilisation du Widget
Le template utilise le widget personnalisé fourni par le plugin. Vous pouvez le retrouver dans l'éditeur Elementor sous le nom de **Kinetic Noir Hero** (ou similaire).
